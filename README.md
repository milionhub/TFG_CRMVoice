# TFG - CRM Voice

Aplicación inteligente para el registro automatizado de actividades comerciales mediante voz.

## Objetivo
Permitir que un comercial registre visitas y tareas hablando, para que el sistema:
- Transcriba el audio.
- Analice el texto con IA.
- Extraiga datos clave.
- Guarde la información en un CRM interno.
- Cree eventos en Google Calendar si hay fechas.

## Estructura del proyecto

frontend/  → App Flutter  
backend/   → API FastAPI  
docs/      → Documentación del TFG
